# 三分钟体验出门啦

**[打开作品](https://leiqingliang.github.io/weekend-city-guide/)**。无需登录，建议先用桌面浏览，再用手机查看同一链接。

## 推荐体验路线

| 时间 | 操作 | 观察重点 |
| --- | --- | --- |
| 0:00–0:35 | 在“想怎么过周末？说来听听。”输入“上海，两个人，100元以内，晴天”，点“找点灵感”，展开一张活动卡的“为什么推荐给我？” | 条件解析、可解释推荐；输入天气会使用明确的情景模式 |
| 0:35–1:20 | 点“帮我安排半天”，进入“我的周末”。调整“开始时间”和“全天预算 / 人”，用活动旁的上移、下移按钮改变顺序；展开“调整餐饮与交通预留” | 时间与费用随操作重算，单项活动预算和全天预算有区别；降低预算可看到差额提醒 |
| 1:20–1:50 | 若计划包含户外活动，把“天气条件”改为“下雨”，点“换成室内方案”，阅读提示后确认 | 不静默改动原计划；替换后重新检查费用和时间 |
| 1:50–2:25 | 点“分享行程”，复制链接到新标签页。先查看“朋友分享了一份周末计划”，再点“载入这份行程”；也可尝试“导出到日历”或“下载文字行程” | 链接还原的是快照；载入前说明覆盖范围，导出保留规划信息 |
| 2:25–3:00 | 在行程活动上点“约搭子”看看集合信息表单，再点“打卡”，写下一句话并“保存这段周末” | 从计划走向同行和记录，回到“我的足迹”可以看到刚保存的内容 |

如果没有合适结果，可先放宽筛选；如果已有计划，“帮我安排半天”会先确认是否替换。体验数据只影响当前浏览器。

还可以继续看：“灵感攻略”中的“写一篇攻略”、保存后的“编辑这篇攻略”和分享；页脚的“备份记录”“恢复备份”；“出发前，看一眼天气”中的联网预报、情景体验与失败重试；页脚“作品说明”。

## 三个产品取舍

1. **把发现和执行放在一起。** 推荐理由帮助选择，时间轴、总预算和雨天方案帮助判断计划是否合适。
2. **先把交互闭环做完整。** 用本机记录和内容链接支持收藏、同行演示、打卡与分享，暂不建设账号、报名后台或票务系统。
3. **区分事实、估算与示例。** 天气来自外部预报并显示状态；活动和价格为示例；25 分钟转场与演出最早 19:00 是排程规则。没有确认实际营业、交通或场次。

## AI Coding 如何参与

作品由 AI Coding 辅助完成需求拆解、界面与交互实现、模块分工、代码检查和测试。实现工作按活动与推荐、天气、行程、数据保存及展示等模块协作，再整合成同一网站。AI 生成内容也需要核对实际行为，代码与测试结果留在仓库中供查看。

“灵感助手”本身采用本地规则解析，不是运行中的大模型服务。这里不宣称个人独立完成全部代码，也不将示例数据或测试结果表述为真实用户研究、运营成果或上线规模。

## 体验边界

联网天气服务可能返回限流或网络错误，此时会明确提供情景模式。小队人数不跨设备同步；分享链接可以转发，既有快照不会随本机删除而撤回。日历导出只创建个人计划文件。个人记录保存在浏览器，清除数据前可先备份。
